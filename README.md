## 我在做什麼 ／ What I build

工具都是從我自己的日常長出來的——研究、教學、寫作卡住了，就做一個來解。留下來的才開源。

- **🧠 認知與臨床評估** — 高齡者書寫與認知測驗的資料處理與分類流程
- **📚 研究工作流** — 文獻管理搬遷、meta-analysis pipeline、知識庫檢索
- **🎓 教學與教練工具** — 網站導覽 skill、網站可見度檢核 skill、skill 打包上架流程、簡報與競賽培訓方法論
- **🌐 內容平台** — 個人網站、腦健康互動工具、碩博士獎助資訊、線上課程
